# JERVIS X

JERVIS X is an advanced Python-based personal AI virtual assistant.

## Current Status

JERVIS X is currently under development.

## Planned Features

- Voice Commands
- Wake Word: "Hey Jervis"
- AI Chat
- Advanced Calculator
- PC Automation
- Smart File Manager
- Memory System
- Web Intelligence
- Document AI
- Computer Vision
- Coding Assistant
- Multi-Agent System
- Security and Permissions
- Plugin System
- System Monitoring

## Technologies

- Python
- CustomTkinter
- SpeechRecognition
- pyttsx3
- SQLite
- OpenCV
- AI / LLM APIs
