# JERVIS-X Roadmap

This roadmap outlines the planned development direction for JERVIS-X. Priorities may change as the project evolves.

## Completed

### Core Assistant

- Text and voice command processing
- CustomTkinter desktop interface
- Calculator and ECE engineering tools
- Notes, tasks, reminders, weather, and news
- System monitoring and diagnostics

### Job Application Intelligence

- Application tracking, search, filtering, and sorting
- Status history and follow-up reminders
- Interview scheduling and preparation
- Offer, joining, onboarding, and career-growth tracking
- CSV export, backup, and restore
- Automated tests with coverage enforcement

### Project Quality

- Windows executable and ZIP packaging
- Automated GitHub releases
- Pytest and GitHub Actions CI
- CodeQL security scanning
- Dependabot dependency monitoring
- SHA-256 download verification
- Command-line help, version, and diagnostics
- JSON diagnostics output

## Planned

### Near Term

- Improve command parsing and error messages
- Add more automated tests
- Add structured application logging
- Improve packaged-app diagnostics
- Add settings import and export
- Improve accessibility and keyboard navigation

### Medium Term

- SQLite-based structured storage
- Plugin architecture for optional features
- Configurable AI providers
- Better offline assistant capabilities
- Resume and job-description matching improvements
- Dashboard charts for job-search progress

### Long Term

- Wake-word support
- Multi-agent task coordination
- Computer vision tools
- Secure desktop automation permissions
- Cross-platform packaging
- Optional cloud synchronization

## Release Goals

- Maintain passing automated tests
- Keep minimum coverage at or above 70%
- Publish checksum-protected Windows releases
- Document significant changes in `CHANGELOG.md`
- Keep security scanning enabled
